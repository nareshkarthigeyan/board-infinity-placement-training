# C++ Containers -> STL

## -> Sequence
(Linear Data Structure)
Array, Vector, Dequee, List, Forward List

## -> Associative 
Set, multiset, map, multimap

## -> Unordered Asociativ Container
unordered_map, unordered_set, unordered_mulitset, unordered_multimap

## -> Container Adapters
Stack, Queue, Priority-Queue

### Vector

add at end -> push_back() --> O(1)
pop -> pop_back(p, v) --> O(n)
insert -> insert(index, value)
v.begin() -> point to the first index
v.end() - point to the last index + 1

.size() - size of vector
